Demo and Application assignment for BazaarGala (bazaargala.com).

Basic 3rd person movement and camera (3-ring rig) and door opening/closing for shops.
Supports Keyboard controls (WASD/Arrows), Mouse/Keyboard (WASD/Mouse for looking around) and Mobile controls.

Built for WebGL, built to perform on mobile devices primarly.

Made and programmed by Juan Pablo Amorocho. No GenAI was used.
